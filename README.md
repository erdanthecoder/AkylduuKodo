# Quickzy

Make a quiz. Host it live. Play it like a game.

- **Classic** — one question at a time on the big screen; faster right answers score more (1000 down to 500), streaks add a bonus.
- **Laser Tag** — a neon arena; answer to recharge your laser.
- **Robot Run** — an endless race on one shared course; answer to recharge and boost.
- **Spacecraft** — blast asteroids; answer to refuel and upgrade your cannon.
- **Obby** — climb one tall tower; answer for more jumps.

Seven question types: multiple choice, true or false, pick all that apply,
type the answer, put in order, number, and poll. Join by PIN or by scanning
a QR code. Accounts with Google or email, password reset and email
confirmation, public profiles, and a verified badge for creators who publish
three quizzes of five questions or more.

Players join as guests, and guests can never read a quiz's answers: the
host's browser marks every answer, and the security rules let each player
write only their own entries.

Set-up, limits and hosting: [docs/SETUP.md](docs/SETUP.md).
